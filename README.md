# Study of Chat Application - Client Server Model

## Aim
To study client-server communication using socket programming.

## Description
This project demonstrates client-server communication using Python and UDP sockets.

## Files
- udp_server.py - UDP server program.
- udp_cilent.py - UDP client program.
- image.png - Project screenshot.
- image-1.png - Project screenshot.

## Technologies Used
- Python
- UDP Protocol
- Socket Programming

## Procedure
1. Run the UDP server program.
2. Open another terminal and run the UDP client program.
3. Test communication between the client and server.

## Result
Client-server communication using UDP socket programming is demonstrated.
